# Fontes locais (auto-hospedadas via `next/font/local`)

Arquivos `.woff2` oficiais mantidos no repositório para garantir builds determinísticos
e sem dependência externa do Google Fonts CDN em build time (ver T27 em `docs/BACKLOG.md`).

- **Geist** (`Geist-Variable.woff2`) e **Geist Mono** (`GeistMono-Variable.woff2`)
  - Origem: [vercel/geist-font](https://github.com/vercel/geist-font)

- **Merriweather** (`Merriweather-Regular.woff2`, `Merriweather-Italic.woff2`, `Merriweather-Bold.woff2`, `Merriweather-BoldItalic.woff2`)
  - Origem: [SorkinType/Merriweather](https://github.com/SorkinType/Merriweather)
  - Licença: SIL Open Font License 1.1 (OFL-1.1)
